# Кукмор — главная страница

Адаптивная статическая страница без зависимостей. Запуск: `npm start`, затем http://localhost:3000. Проверка JavaScript: `npm run check`.

Макеты: desktop >1100px, tablet 541–1100px, mobile ≤540px. Меню, слайдер и окно консультации работают на клиенте. Контакты используют `tel:`. Публикация не выполнялась.

В `assets/` находятся временные SVG-иллюстрации: для точного соответствия макету необходимо заменить их оригинальными фотографиями и изображениями оформления. Заявки на сервер не отправляются; консультация доступна по телефону.
